# Content and UX copy

Tone: clear, intelligent, professional, calm, direct. Indian in perspective, global in scope.

Use: research, understand, compare, track, explore, monitor, data, market context, "Add to watchlist", "Add alert",
"View holdings", "Data source", "Last updated".
Avoid: revolutionary, game-changing, best-ever, guaranteed, profit, get rich, aggressive trading language, clickbait,
buy/sell, "you should".

Rules
- Sentence case. Plain verbs. A button says what happens ("Save screen" → toast "…saved").
- Errors say what failed and how to fix it; no apologies, no vagueness. Empty states say what to do next.
- Never "Updating…". Always a status and an exact time ("As of 14:32 IST").
- Research: describes data, separates measurement from commentary, names asset / market / topic / date. No ratings,
  no targets, no personalised advice. Scores, if added, are labelled "INRGIFT Research Score" and "not financial advice".
- Standard disclaimer: "INRGIFT is a research and information platform. It is not a broker or an investment adviser."
- Demo: "Demo data — connect a live provider to enable production market feeds."
- Missing data: "No fundamentals available for this security." / "Data unavailable from source." / "Market closed."
- Indian number context where useful: ₹, lakh crore, IST.
