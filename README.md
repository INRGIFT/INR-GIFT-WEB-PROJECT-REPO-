# INRGIFT

Global market intelligence from India. Every market. Every asset. One research view.
A research platform: not a broker, no trading.

```bash
npm install
npm run dev
```

Runs with no configuration on demo market data and a browser-local demo account (any email and password; the
verification code is `123456`). Copy `.env.example` to `.env.local` to connect Supabase or a real data provider.

Start with `CLAUDE.md`, then `docs/ROADMAP.md` for what is built and what is next.
